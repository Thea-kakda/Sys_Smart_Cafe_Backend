Single Spring Boot application (`com.smartcoffee.SmartCoffeeApplication`) organized as a layered monolith with domain modules under `src/main/java/com/smartcoffee/modules/` (identity, auth, rbac, organization, customer, catalog, recipe, inventory, cart, ordering, payment, receipt, production, promotion, loyalty, notification, audit, settings). Cross-cutting concerns live in `common/` (API envelope, exceptions, money, persistence base, security, context propagation) and `infrastructure/` (cache, idempotency, messaging via RabbitMQ, notification, observability, payment adapters, WebSocket realtime, MinIO storage). Configuration is centralized in `config/` (JPA, Redis, RabbitMQ topology, Security/OAuth2 resource server, OpenAPI, Jackson, async/scheduling, WebSocket). Data access uses Spring Data JPA with Flyway migrations under `resources/db/migration/` (V001–V012 covering identity through outbox claiming). External services are orchestrated via `compose.yaml` (PostgreSQL 18, Redis 7.4, RabbitMQ 4 management, MinIO) and consumed through Spring Boot's service-connection labels; Docker image built multi-stage from `maven:3.9-eclipse-temurin-17` to a JRE 17 runtime on port 8080. Integration tests use Testcontainers for Postgres and RabbitMQ, and Failsafe runs `*IT.java` suites.
