Run all dependencies with `docker compose up -d` (Postgres on :5433, Redis on :6379, RabbitMQ on :5672/:15672, MinIO on :9000/:9001). Build with `./mvnw package` (Dockerfile uses Maven 3.9 + Temurin 17). Integration tests execute via `mvn verify` which triggers Failsafe against Testcontainer-backed Postgres and RabbitMQ. Application properties are loaded from `src/main/resources/application.yml`; environment variables can be supplied via `.env.example`.
